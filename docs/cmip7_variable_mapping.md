# Mapping of ESA CCI datasets to CMIP7 variables

This table maps each dataset in the xcube `esa-cci-zarr` data store to
the CMIP7 variable it could provide, as a starting point for new
recipes. Where there is no CMIP7 variable, it gives the ESMValTool
custom variable, if there is one. It does not guess: if no mapping is
certain, it says "No match found".

It is based on, as of 2026-10-07:

- The variables, units and time steps in the Zarr metadata of the 45
  datasets that xcube lists in the `esa-cci-zarr` store.
- The ESMValTool CMORizer configurations [`ESACCI-*.yml`](https://github.com/ESMValGroup/ESMValTool/tree/main/esmvaltool/cmorizers/data/cmor_config).
  These use the CMIP5 tables (`project_id: OBS`) or the CMIP6 tables
  (`project_id: OBS6`), so the CMIP7 variable can differ slightly.
- The [CMIP7 CMOR tables](https://github.com/WCRP-CMIP/cmip7-cmor-tables/tree/main/tables).
- The ESMValTool custom variables in the
  [ESMValCore custom table](https://github.com/ESMValGroup/ESMValCore/blob/936450c81d6b00ede72947310fc04e322c7654c1/esmvalcore/cmor/tables/cmip6-custom/CMIP6_custom.json).

Columns:

- **Variable**: the ESA CCI variable and the variable it maps to.
- **Type**:
  - **CMIP7**: an official CMIP7 branded variable.
  - **ESMValTool custom (not CMIP7)**: a variable from the ESMValCore
    custom table, linked to its definition. It is not part of CMIP7,
    has no branding suffix, and CMIP7 models do not produce it, so it
    is only useful for evaluation with ESMValTool.
- **Branding suffix** and **Realm**: of the CMIP7 variable. The realm is
  the CMIP7 table it is in, or for custom variables, their
  `modeling_realm`.
- **Basis**: the ESMValTool CMORizer configuration that maps the same
  variable, if there is one. It often uses another product or version.
- **Differences**: how the ESA CCI variable differs from the same
  variable produced by CMIP7 climate models, and the conversion needed.
