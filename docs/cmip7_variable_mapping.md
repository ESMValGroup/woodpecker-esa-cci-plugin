# Mapping of ESA CCI datasets to CMIP7 variables

These tables map each dataset that xcube provides in the
[`esa-cci-zarr`, `esa-cci-kc` and `esa-cci`](#stores) data stores to the CMIP7
variable it could provide, as a starting point for new recipes. There is
a table for each [essential climate variable](#essential-climate-variables).
Where there is no CMIP7 variable, they give the ESMValTool custom
variable, if there is one. They do not guess: if no mapping is certain,
they say "No match found".

They are based on, as of 2026-10-07:

- The variables, units and time steps in the metadata of the datasets
  that xcube lists in the stores.
- The ESMValTool CMORizer configurations [`ESACCI-*.yml`](https://github.com/ESMValGroup/ESMValTool/tree/main/esmvaltool/cmorizers/data/cmor_config).
  These use the CMIP5 tables (`project_id: OBS`) or the CMIP6 tables
  (`project_id: OBS6`), so the CMIP7 variable can differ slightly.
- The [CMIP7 CMOR tables](https://github.com/WCRP-CMIP/cmip7-cmor-tables/tree/main/tables).
- The ESMValTool custom variables in the
  [ESMValCore custom table](https://github.com/ESMValGroup/ESMValCore/blob/936450c81d6b00ede72947310fc04e322c7654c1/esmvalcore/cmor/tables/cmip6-custom/CMIP6_custom.json).

Columns:

- **Variable**: the ESA CCI variable and the variable it maps to, with
  its realm in parentheses:
  - CMIP7 variables are given by their branded name, e.g.
    `prw_tavg-u-hxy-u` for variable `prw` with branding suffix
    `tavg-u-hxy-u`. The realm is the CMIP7 table they are in.
  - Variables marked **custom** are ESMValTool custom variables from the
    ESMValCore custom table, linked to their definition. They are not
    part of CMIP7, have no branding suffix, and CMIP7 models do not
    produce them, so they are only useful for evaluation with
    ESMValTool.
- **Basis**: the ESMValTool CMORizer configuration that maps the same
  variable, if there is one. It often uses another product or version.
- **Differences**: how the ESA CCI variable differs from the same
  variable produced by CMIP7 climate models, and the conversion needed.

## Stores

- `esa-cci-zarr` (also `esa-cdc-zarr` and `ccizarr`): datasets in Zarr
  format in the ESA CCI object storage. Their names end in `.zarr`.
- `esa-cci-kc` (also `esa-cdc-kc` and `ccikc`): virtual Zarr stores,
  Kerchunk references to the original netCDF files. Their names end in
  `kr1.0`, `kr1.1` or `kr1.2`.

- `esa-cci` (also `esa-cdc`, `esa-climate-data-centre` and `cciodp`):
  the datasets of the ESA CCI Open Data Portal, read with OPeNDAP. Their
  names start with `esacci.`.

Some products are in several stores, sometimes in other versions.
